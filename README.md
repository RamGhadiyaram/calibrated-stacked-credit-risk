# Calibrated Stacked Ensembles for Explainable Credit Risk Scoring

Code and results for the paper "Calibrated Stacked Ensembles for Explainable Credit Risk Scoring Under Tariff-Driven Volatility: An Attention-BiLSTM and XGBoost Framework" (R. Ghadiyaram and S. K. Kaata), 3ICT 2026.

## Contents
- `pipeline_revision.py`: synthetic generator, data loaders, learners (logistic, XGBoost, LightGBM, CatBoost, attention-BiLSTM), nested repeated cross-validation with out-of-fold stacking, raw, Platt and isotonic calibration.
- `analyze.py`: result tables, Nadeau-Bengio paired tests, reliability diagrams.
- `shap_figs.py`: TreeSHAP and KernelSHAP figures.
- `loss_sim.py`: portfolio loss simulation on the simulated portfolio.
- `verify_paper.py`: recomputes the paper's tables and key claims from the outputs and compares them to the manuscript LaTeX.
- `notebooks/credit_risk_3ict_reproduce.ipynb`: one-shot Google Colab notebook; keeps all inputs and outputs in a Google Drive folder.
- `results/`: tables from the reported run and the exact package versions. `figures/`: paper figures.

## Reproduce in Colab
Open the notebook, put the five scripts and `south_german_credit.asc` in `MyDrive/credit_risk_3ict/code`, and run all cells. Finished datasets are skipped on re-run. Runtime on CPU is about 20 minutes each for the synthetic and Taiwan runs and about 11 minutes for German.

## Reproduce locally
```bash
pip install -r requirements.txt
export CR_BASE=.            # project root; data/ and out/ live under it
python pipeline_revision.py --data synth --repeats 3
python pipeline_revision.py --data german --repeats 3
python pipeline_revision.py --data taiwan --repeats 2 --n_max 10000
python analyze.py
python shap_figs.py
python loss_sim.py
```
## Data
- South German Credit (corrected): UCI, doi 10.24432/C5QG88. Convert to `data/GermanCredit.csv` as shown in the notebook (cell 3).
- Taiwan credit-card default: UCI id 350, fetched by the notebook (cell 4) to `data/taiwan_credit.csv`.
- The simulated portfolio is generated by `make_synth` in `pipeline_revision.py`.

Seeds are fixed at 42. The neural learner can differ in the third decimal across hardware and package versions. The simulated portfolio and the loss figures are illustrative, not a forecast.

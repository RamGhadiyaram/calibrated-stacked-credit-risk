# Calibrated Stacked Credit Risk

Reproduction code and results for a calibrated stacking ensemble for credit-risk prediction.

The pipeline combines strong tabular models (XGBoost, LightGBM, CatBoost), a logistic baseline, and an Attention BiLSTM, then applies post-hoc calibration (isotonic / Platt). Evaluation uses repeated stratified cross-validation with reliability diagrams, ECE, calibration slope & intercept, and portfolio-loss simulation.

## Repository layout

```
calibrated-stacked-credit-risk/
├── pipeline_revision.py   # Main experiment script (R2 revisions)
├── analyze.py             # Aggregate fold metrics → tables
├── shap_figs.py           # TreeSHAP + KernelSHAP figures + loss sim
├── verify_paper.py        # Check paper numbers against CSVs
├── paper.tex              # LaTeX source of the paper
├── requirements.txt
├── data/                  # German, Taiwan, and synthetic fold metrics
├── figures/               # Reliability diagrams + SHAP plots
├── results/               # Final tables, coefficients, rankings
├── logs/                  # Run logs
└── notebooks/             # (optional) Jupyter notebooks
```

## Quick start

```bash
# 1. Create environment
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 2. Run the main pipeline (example: synthetic data, 3 repeats)
python pipeline_revision.py --data synth --repeats 3

# 3. Aggregate results into tables
python analyze.py

# 4. Generate SHAP figures (TreeSHAP on XGBoost, KernelSHAP on stack)
python shap_figs.py

# 5. Verify numbers against paper.tex
python verify_paper.py paper.tex results
```

Supported datasets: `synth`, `german`, `taiwan`.

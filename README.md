# Calibrated Stacked Ensembles for Explainable Credit Risk Scoring

Code for the paper "Calibrated Stacked Ensembles for Explainable Credit Risk Scoring Under Tariff-Driven Volatility: An Attention-BiLSTM and XGBoost Framework" (R. Ghadiyaram and S. K. Kaata).

## What is here
- `pipeline_revision.py`: synthetic generator, loaders, learners (logistic, XGBoost, LightGBM, CatBoost, attention-BiLSTM), nested repeated CV with out-of-fold stacking, raw/Platt/isotonic calibration.
- `analyze.py`: result tables, Nadeau-Bengio paired tests, reliability diagrams.
- `shap_figs.py`: TreeSHAP and KernelSHAP figures.
- `results/results.md`: the tables reported in the paper. `figures/`: paper figures.

## Reproduce
```bash
pip install -r requirements.txt
python pipeline_revision.py --data synth --repeats 3 --out out
python pipeline_revision.py --data german --repeats 3 --german_path SouthGermanCredit.asc --out out
python pipeline_revision.py --data taiwan --repeats 2 --n_max 10000 --taiwan_path taiwan.csv --out out
python analyze.py
python shap_figs.py
```
Data: South German Credit (UCI, doi 10.24432/C5QG88) and Taiwan credit-card default (UCI id 350) are downloaded separately. The synthetic portfolio is generated by the code. Seeds are fixed at 42; the neural learner can differ in the third decimal across hardware.

## Note
The simulated portfolio and loss figures are illustrative, not a forecast.

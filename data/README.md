# Data

Both datasets are public and are included so the benchmark runs without downloads.

- `GermanCredit.csv`: South German Credit (corrected), Groemping 2019, UCI Machine Learning Repository, doi 10.24432/C5QG88, licensed CC BY 4.0.
- `taiwan_credit.csv`: Default of Credit Card Clients (Yeh and Lien 2009), UCI Machine Learning Repository, id 350, doi 10.24432/C55S3H, licensed CC BY 4.0.

Please cite the original sources when you use them.
